Projet de Stage — Refonte du site web de Qolibri & Cie
À propos
Ce projet a été réalisé dans le cadre de mon stage de deuxième année de BUT Informatique au sein de l’entreprise Qolibri & Cie, cabinet de recrutement et de conseil RH spécialisé dans l’accompagnement des entreprises et des talents.

Objectif
L’objectif principal de ce projet était de repenser entièrement le site vitrine de l’entreprise, tant sur le plan graphique que fonctionnel.
Les enjeux étaient les suivants :

Moderniser le design et l’expérience utilisateur

Structurer le contenu de manière claire et accessible

Améliorer la navigation et l’ergonomie sur tous les appareils

Mettre en avant les services et l'identité de l'entreprise

Ajouter des interactions dynamiques et du contenu visuel engageant

Technologies utilisées
HTML5 / CSS3

JavaScript (vanilla)

Responsive Design (Flexbox, Media Queries)

Git / GitHub pour la gestion de version

Outils de test sur navigateur mobile (iPhone 12 Pro notamment)

Fonctionnalités développées
Menu de navigation responsive avec ouverture latérale (burger menu)

Animations dynamiques au scroll et au clic

Affichage conditionnel de sections (masquées par défaut puis affichées)

Slider automatique des témoignages

Marquee textuel défilant en boucle dans le footer

Mise à jour automatique de l’année dans le copyright

Respect de la charte graphique fournie par l’entreprise

Structure des pages
Accueil

Entreprises (et ses sous-sections dynamiques via les onglets)
